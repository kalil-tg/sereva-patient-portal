# Design Fidelity Ledger

Accepted concepts: `design/01-dashboard-concept.png`, `02-results-concept.png`, and `03-refill-mobile-concept.png`.

| Area | Comparison and result |
| --- | --- |
| App shell | Persistent left rail, quiet user header, main care column, and right utility rail matched |
| Dashboard density | Two care tasks, message row, appointment panel, and medication list matched |
| Results table | Four-column anatomy, highlighted first row, explicit status icons/text, and spacing matched |
| Chart/note split | Reference band, six points, action stack, and caution retained |
| Mobile dialog | Dim context, bottom sheet, medication summary, labelled controls, note, and actions matched |
| Palette/type | Warm-white, forest, sage, coral, Space Grotesk, and Inter locked to the design world |

Fixes made after comparison: darkened coral/orange tokens after automated contrast findings; reduced mobile dialog height to reveal useful dashboard context; generated and integrated a dedicated rosette brand asset instead of a placeholder mark.

Intentional deviations: the concept’s incorrect 2025 date was corrected to 2026; chart dimensions were simplified for robust responsive SVG scaling; no fictional diagnosis or outcome claim was added.
