# Manual QA Plan

Before broader conformance claims:

- Complete keyboard traversal and focus-return testing for every dialog path
- Test NVDA with current Chrome and Firefox on Windows
- Test VoiceOver with Safari on macOS/iOS when available
- Verify table navigation, chart description/data, dynamic dialog naming, and success announcements
- Test forced colors, 200%/400% zoom, text-spacing overrides, and 320px reflow
- Have clinical copy reviewed by an appropriate healthcare subject-matter expert before real use
- Record exact browser/AT versions, scenario, result, defect, and retest
