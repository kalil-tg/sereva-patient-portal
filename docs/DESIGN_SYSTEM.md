# SEREVA Design System

- Direction: calm clinical editorial product UI
- Display: Space Grotesk
- Interface: Inter
- Background: soft warm white
- Primary: deep forest green
- Attention: dark coral and dark orange, tuned to exceed text contrast thresholds
- Secondary: pale sage
- Geometry: 6–8px corners, thin rules, minimal elevation
- Containers: persistent rail, open lists, one appointment panel, semantic table, and native dialog

Statuses always include text. Charts always have a programmatic description and equivalent data. Controls use native behavior where it reduces risk.
