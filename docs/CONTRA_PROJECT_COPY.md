# Contra Project Copy

## Title

SEREVA — Accessible Patient Portal and Lab Results

## Short description

A patient-facing React portal with explicit care states, semantic lab results, chart alternatives, and an accessible refill dialog.

## Overview

SEREVA is a self-initiated technical case study for a fictional healthcare portal. I designed and built the dashboard, result detail, chart evidence, and medication-refill interaction, then added reproducible accessibility regression coverage.

The result uses written statuses instead of color alone, semantic data tables, an accessible SVG description, an expandable chart-data alternative, a native modal form, deliberate focus movement, responsive reflow, and reduced-motion support.

## Deliverables demonstrated

- React and TypeScript product engineering
- Complex dashboard and patient-result UX
- Semantic tables and accessible data visualization
- Native dialog, labelled form controls, and success state
- Keyboard/focus behavior and mobile overflow protection
- Playwright and axe-core regression tests

Five end-to-end scenarios pass. This is not medical advice and does not claim certification, legal compliance, or completed screen-reader validation.
